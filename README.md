# StockTradingSignal
Buy : The scanner looks for a stock where KDJ and MACD recently turned bullish, and the stock is trading above its 20-day moving average. Sell: If you already hold the stock, the scanner checks whether weakness is appearing, such as a MACD bearish cross, price falling below the 10-day moving average, three down days in a row, or a 10% stop-loss.
